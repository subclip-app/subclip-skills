# Internal tool map

## Local editor gateway

- `mcp_editor__list_tools`: search every deferred native editor tool by domain or capability and optionally return exact input schemas
- `mcp_editor__call_read_tool`: invoke one discovered read-only editor tool
- `mcp_editor__call_tool`: invoke one discovered editor mutation
- Tool names in the sections below are delegated names supplied in the gateway's `tool` field

## Inspect

- `get_project_outline`: first read; compact revision, canvas, lane counts and item timing/IDs
- `read_project_section`: one lane, optional item IDs and fields; explicitly request large fields to hydrate `$ref` values
- `read_layer_source`: numbered source lines and source hash
- `edit_layer_source`: validated exact-text or line-range patches with expectedSourceHash
- `get_current_project` / `get_project`: compatibility full reads; prefer outline and targeted sections, never repeatedly fetch the whole document
- Project-state reads accept `ifRevision`; matching revisions return only `{ unchanged: true, revision }`
- `get_project_director_brief`: read project-local `director.md`, the concise cross-session source of truth; also returns `hasBrief` and the latest `projectLog` entries (read first when picking up a project)
- `list_projects`: newest first, each with brief, latest summary, duration, canvas, layer counts and a thumbnail image; `query`, `limit`, `cursor`, `includeThumbnails` (see `subclip-project-log`)
- `get_project_log`: the trail of work on a project (what was asked, done, still open); entries with `autoGenerated: true` were written by Subclip because the agent wrote none
- `write_session_summary`: before finishing, record `request`, `summary`, `did`, `openIssues`; replaces the automatic note
- `validate_project`: verify that an exact saved project can open and that core media/audio timeline references resolve; required after project creation or cloning before completion
- `get_transcription_status`: compact caption-word and exact local/cloud job lifecycle; pass the `jobId` returned by `transcribe_project` and do not treat pre-existing words as completion of a replacement run
- `create_dubbing_workspace`, `get_dubbing_workspace`, `update_dubbing_translations`: assistant-owned semantic translation workspace built from exact-item captions; the hidden Markdown is scratch and state.json owns exact IDs/attempts
- `set_dubbing_speaker_voice`, `prepare_dubbing_temporary_voice`: assign a live catalog voice or prepare one explicitly authorized, expiring per-speaker clone without importing its reference into AudioPanel
- `generate_dubbing_segments`: generate up to 12 translated utterances per bounded paid batch and resume the in-app assistant once the aggregate batch is terminal
- `commit_dubbing_workspace`, `discard_dubbing_workspace`: atomically import reviewed segment audio before optional source muting, or clean an abandoned uncommitted workflow
- `list_editor_assets`: concise canvas, playhead, media, audio, text, Motion, HyperFrames, Remotion, native 3D, and Elements inventory; framework source is represented by hash/byte count until requested explicitly
- `list_3d_models`, `list_3d_animation_presets`, `inspect_3d_composition`, `get_3d_layer`, `inspect_3d_glb`: approved model/animation discovery, imported GLB clips/cameras, and exact native 3D state inspection
- `list_canvas_background_presets`: bundled midnight, daytime, landscape, and `colorFlow-1` through `colorFlow-74` image IDs shared by canvas, 3D scene, and device-screen background tools
- `list_runtime_layer_templates`: built-in HyperFrames and Remotion template IDs, metadata, defaults, and opt-in source
- `list_motion_graphics_templates`: every Motion Graphics template across Remotion, HyperFrames, and HTML/CSS. Resolve an exact @ catalogId/templateId or search, then invoke returned importTool/importArguments. Source and full defaults are opt-in. Maps include `map-explainer` (Cesium) and `river-sequence` (flat vector).
- `get_runtime_layer`: exact source plus variables/props for one framework item
- `validate_runtime_layer_source`: read-only static validation of source, imports, external URLs, and variables/props
- `validate_html_motion_source`: read-only validation for the compact script-free HTML/CSS fallback before persistence
- `view_current_frame`: live rendered frame image for visual review; pass the same `projectId` used for the edit
- `list_project_history`: available recoverable revisions
- `fetch_public_github_pull_request`: read a public GitHub PR URL directly, including metadata, files, commits, and exact diff
- `mcp_remote__list_tools`: discover connected-service tools and their schemas/read-only declarations
- `mcp_remote__call_read_tool`: invoke only a connected tool that declares `readOnlyHint: true`; use for GitHub profiles, PRs, commits, files, diffs, releases, and tags
- `create_route_map_geometry`: generate a familiar fixed-orientation Natural Earth world map with a continuous visible route, coordinate-bound pins/shockwaves, displayed distance, editorial Text timings, and an editable GPU-friendly single-direction camera block with zoom tuning inputs
- `plan_globe_route`: plan a Cesium globe route from exact endpoint coordinates and direct/Pacific/Atlantic/custom waypoints, returning editable props and camera controls. Ocean presets describe illustrative journeys, not validated shipping routes.
- `inspect_public_website`: render a public product/marketing page in isolated Electron, extract verified copy and computed brand tokens, and save real project-local page/logo PNGs for native Media import

## Create and arrange

- `create_project`: create a separate empty same-owner project with its own stable ID/package/history; intended for an explicitly requested multi-project workflow
- `create_project_from_template`: new project at a gallery template's own canvas with the template placed (catalogId from `list_favorite_templates` or `list_motion_graphics_templates`)
- `list_favorite_templates`, `set_favorite_template`: the creator's starred gallery templates
- `list_workspace_gallery_templates`, `save_gallery_template_to_workspace`, `remove_gallery_template_from_workspace`: gallery templates saved in workspaces
- `clone_project`: create a separately editable variant of a same-owner project without changing its source
- `authorize_multi_project_editing`: grant the current agent session write access to exact existing same-owner project IDs after explicit user authorization; grants expire with the session
- `get_project_chat_history`: read same-owner project conversation summaries or one sanitized user/assistant transcript; use original prompts and follow-ups as supporting intent context while live saved state remains authoritative
- `rename_project`: assign a release-quality one- or two-word title based on the finished story, subject, or visual payoff; avoid framework/tool/task names such as `Prompt Fix` or `HyperFrames Test`, and use `onlyIfUntitled` to preserve creator-authored names
- `add_text_overlay`: create a TextPanel/TextLayer item
- `place_editor_asset`: place an existing MediaPanel or AudioPanel file by ID; media defaults to a full-canvas `cover` container unless explicit framing is supplied
- `set_media_framing`: reliably switch a selected image/video between contain and cover
- `apply_screenstudio_layout`: atomically arrange a rounded tutorial stage with a circular muted presenter picture-in-picture
- `apply_two_way_split_scene`: split tutorial and presenter items at both scene boundaries, then give only the isolated middle segments editable left/right canvas containers and separate lanes
- `import_external_media`: import an image, video or audio file you made outside Subclip (Codex image generation, Grok, a local tool) from an absolute `path`, a public https `url` or inline `base64`; optional `startTime`, `durationSeconds`, `addToTimeline`, `projectName`; Subclip generation (`generate_ai_media`) stays optional
- `import_generated_media_to_timeline`: bring a locally generated/revised file into MediaPanel, optionally replacing an existing item's source without losing its layout; on the first import into an untitled empty project, pass the agent's one- or two-word `projectName`
Use the dependency already provided by Subclip. If the import is unavailable, choose a supported alternative; do not install packages inside the layer.
- `import_generated_audio_to_timeline`: add project-local generated audio as an editable AudioPanel item
- `set_media_loop_and_duration`: explicitly loop or extend a source only when the user requests that timing change; ScreenStudio/presenter layouts must not invoke it automatically
- `save_screenshot`: capture the screen (display or region) and save it to the user's Screenshot folder, optionally copy / reveal in Finder, no picker
- `list_shared_items` / `update_shared_video` / `update_shared_project` / `delete_shared_item`: manage cloud shared videos and projects (rename, access, emails, downloads, auto-delete; delete needs confirm: true and the user's OK)
- `edit_screenshot`: edit a picture or fresh capture with no editor window: crop, annotations (arrow, line, rect, ellipse, circle, highlight, text, redact, callout, magnifier), frame (background, padding, roundness, shadow, aspect, device mockup, tilt, watermark); saves to the Screenshot folder
- `share_video_file`: upload any local video file (not only Subclip exports) and get a Subclip watch link; optional name, defaults to the file name; paid plan required; runs in the background, so poll `get_video_share_status` with the returned jobId and never call it twice for one file
- `share_project`: share a saved project (or Recorder recording) as a Subclip shared-project link; name, access, allowedEmails, allowDownload; paid plan required; background, poll `get_project_share_status`; it is also the push of cloud sync (updates the same link; refused when a newer version was published: pull first)
- `list_synced_projects`: the user's own shared (cloud) projects and the local projects tracking each, with state (up-to-date, ahead, behind, diverged)
- `get_sync_status`: one local project's sync state with its shared project and what to do next
- `pull_project`: `projectId` updates a local project from the latest cloud version (only missing media is copied; undoable); `onConflict` "abort" (default), "theirs" (ask the user first) or "copy"; `sharedProjectId` (or showcase link) without projectId downloads it as a new tracking project
- `extract_timeline_audio`: audio of media already in the project (item, lane or whole timeline, optional time segment) as a mixdown or per-clip WAV; revealInFinder / addToTimeline options
- `remove_timeline_audio`: video only; mute (or restore) clips by item, lane, whole timeline or time segment, splitting at the segment edges
- `set_all_video_audio`: mute/unmute every video item together, especially when an AudioPanel item is the master soundtrack
- `seek_timeline`: move the playhead to an exact time before frame inspection
- `import_attachment_to_timeline`: promote an attached image/video into MediaPanel and place it; on the first import into an untitled empty project, pass the agent's one- or two-word `projectName`
- `import_attachment_clip_with_ffmpeg`: enqueue one native compatibility import and immediately return its `jobId`; it prefers system FFmpeg, hardware H.264 and a cached 1920px full-source proxy, then applies the requested range as native in/out points; pass `replaceItemId` to swap an already-placed black/undecodable source in place
- `get_media_import_status`: external/status-check fallback for one exact compatibility job; the in-app coding agent is resumed by terminal events instead of polling
- `cancel_media_import`: terminate one obsolete queued/running conversion and discard its partial output
- `get_media_runtime`: report the native system/bundled FFmpeg boundary and renderer-side MediaBunny runtime; confirms no FFmpeg WASM is used
- `set_text_animation`: apply a native TextLayer animation preset
- `add_html_motion_graphic`: create one new deterministic, script-free HTML/CSS Motion-panel item after `validate_html_motion_source`; use this only when it is materially simpler than Remotion or HyperFrames
- `update_html_motion_graphic`: revise an existing Motion-panel item in place; use it for layout/timing/content corrections instead of creating overlapping copies
- `delete_html_motion_graphic`: remove one exact superseded or accidental Motion-panel draft during final cleanup
- `add_runtime_layer`: create one validated HyperFrames or Remotion item from a built-in template ID or exact source
- `update_runtime_layer`: revise one exact framework item in place, including source/bindings, time, geometry, fit, opacity, lane, z-index, and layer order
- `clone_runtime_layer`: create a numbered editable framework-layer variant
- `delete_runtime_layer`: remove one exact HyperFrames or Remotion item through recoverable project history
- `add_3d_layer`, `clone_3d_layer`: create or duplicate a native editable 3D device with verified model and screen-media IDs
- `update_3d_layer`: rename, retime, place, aspect-resize, reorder, transform, light, and set transparent/color/image scene backgrounds
- `set_3d_screen_content`, `set_3d_screen_appearance`, `clear_3d_screen_content`: independently manage device screen media, timing, fit, padding, roundness, and background without unintended resets
- `list_3d_keyframes`, `set_3d_keyframe_sequence`, `create_3d_keyframe`, `update_3d_keyframe`, `duplicate_3d_keyframe`, `delete_3d_keyframe`, `clear_3d_keyframes`: complete editable model/camera/canvas keyframe lifecycle
- `append_3d_animation_preset`, `apply_3d_animation_preset`: reviewed preset controls; append preserves existing motion while apply replaces it
- `add_glb_3d_layer`, `inspect_3d_glb`: import a glTF 2.0 binary (.glb, e.g. a Blender export) as a native 3D layer (`modelId: "custom-glb"`, auto-framed, no device screens), and validate a file or read an imported layer's clips and cameras; it renders inside Subclip and exports with `export_video`. Embedded clip playback, GLB cameras and storyboard camera cuts are set with `update_3d_layer` (`glbAnimation`, `glbCameraSource`, `glbCameraCuts`)
- `set_canvas_properties`: choose landscape, vertical, or square canvas and optionally set its background
- `set_project_duration`: set the exact final timeline and canvas-background endpoint; it reports any media, audio, text, motion, or caption items that must be shortened or removed first
- `split_timeline_item`: split with UnifiedTimeline semantics; caption words owned by a split media or audio clip move to the half they play in
- `delete_timeline_item`: remove one exact media, audio, text, 3D, or canvas-background item through native UnifiedTimeline logic; prompt checkpoints and Undo make it recoverable, so explicit user-authorized deletion does not need another approval prompt
- `delete_project_assets`: after an explicit request, remove exact MediaPanel/AudioPanel file IDs plus every linked timeline placement; pass `confirmed: true`, then re-list assets to verify the file and linked item IDs are absent

## Fine control

- `update_caption_words`: change caption text/timing
- `update_caption_style`: change project-wide caption typography, color/background card, outline/shadow, placement, width, and animation without guarded raw-state writes
- `assign_caption_speaker`: reassign only one caption page, exact word set, or time range to an existing speaker identity
- `create_caption_speaker`: add a new named speaker identity before assigning it to a caption segment
- `rename_caption_speaker`: rename one speaker identity across the project speaker list and every assigned caption word
- `set_caption_segment_visibility`: hide or restore one caption segment in preview/export without deleting its transcript
- `delete_caption_segment`: permanently remove an exact caption page, word set, or time range; use this only for explicit delete/remove intent and verify the words are absent afterward
- `get_script` (read-only): the transcript as paragraphs of word ids with timeline times and hidden flags, pauses, and cut words with their cut ids; read it before any text-based edit
- `cut_script_words`: ripple-cut words (by `wordIds`) or a time range from the video: media and audio split by source time, every later lane moves left, captions keep their clips; restorable
- `restore_script_cut`: put back the exact media, layers and words of a script cut (cut id or group id)
- `hide_script_words`: hide (`hidden: true`) or show caption words by id without cutting the video; the words leave or rejoin the caption pages
- `propose_script_cleanup` (read-only) / `apply_script_cleanup`: list then cut filler words (en, fr) and long pauses; apply needs the proposed `revision`, `confirm: true`, and optional `excludeIndexes`
- `set_caption_speaker_visibility`: hide or restore all rendered captions assigned to one speaker
- `convert_captions_to_hyperframes`: turn native caption words into one transparent HyperFrames caption layer (words kept in layer variables), hiding the native captions reversibly; re-run updates the same layer; pass `script` to caption generated speech directly with no transcription; see `$subclip-hyperframes-captions`
- `get_audio_timeline_sheet` (read-only): see the sound. One image plus JSON for a time window (`startSeconds`, `endSeconds`, max 300 s): lanes for voice, music, effects and other with real waveforms, mix waveform, spectrogram, LUFS curve with -14/-16 lines, cut marks and sound starts; warnings for peaks above -1 dBTP, clipping, silence over 1.5 s, overlapping effects, music too loud under the voice, cuts without sound (`cutSync.percentInSync`)
- `view_frame`: quick look at 1-8 moments as small JPEGs (default 720 px, rendered at that size, cached while the project is unchanged); use it while iterating, `view_current_frame` for the final full-size check, `skipHyperframes:true` when HyperFrames layers are not the point (on Linux without a GPU a heavy HyperFrames layer is left out automatically and the result says so; pass `skipHyperframes:false` to force it, which can take minutes)
- `get_app_update_status` (read-only): app version, update phase (idle, checking, downloading, ready, up-to-date, error), percent, available version, `installPending`, and `canInstallNow` with the reason when a recording, export or download is running
- `check_for_app_update`: start an update check (same as Check for Updates in the menu bar); a newer version downloads by itself and waits for a restart, nothing restarts
- `sign_in` (works signed out): device-code sign-in; returns `verificationUriComplete`, `userCode`, `expiresIn`, `interval`, `openedBrowser` (true when it opened this computer's browser; always false headless). Show the link and the code to the human, who approves on subclip.app; then poll `get_sign_in_status`
- `get_sign_in_status` (read-only, works signed out): signed in or not, the pending code's state, this device (`device.headless` true = no screen), and the local MCP `tokenFingerprint`/`tokenHint`/port (never the token)
- `sign_out`: `confirm:true`, only when the human asks
- `open_upgrade_page` (`plan?` monthly|lifetime, `reason?`): only when the creator wants to upgrade or an export/feature said it needs a paid plan; opens subclip.app pricing (when a screen exists) and returns `url`, `openedBrowser`, `hasPaidPlan`. Give the human the link; never act on the checkout page
- `install_app_update_and_restart` (destructive, needs `confirm:true`): restart to install a downloaded update; refused when no update is ready or work is running unless `force:true`; relaunches into the menu bar only, MCP is down for a few seconds. Use only when the creator asked for the update. Linux .deb/.rpm with nobody to enter a password (headless, locked screen): refused with `refused: "needs-admin"` and `manualInstallCommand`; give the human that command (see references/headless.md)
- `reset_background_processes`: fix a stuck render without quitting (stops HyperFrames renders, kills leftover render browsers); `restart:true` relaunches Subclip into the menu bar only and is refused while a window is open or a recording or export runs. Never ask the user to quit the app; an MCP client cannot reopen it
- `restore_native_captions`: undo that conversion: un-hide exactly the words it hid and remove the HyperFrames caption layer
- `update_media_item`: complete native MediaPanel controls—trim, sound, playback, crop/focus, transform/container, opacity/fades, style/effects, transition type and UI animation speed, composition-plane placement, lane, and z-order
- `replace_media_item_source`: atomically use another item/file as a target clip's source while preserving the target timeline slot, framing, styling, mute policy, lane, and z-order
- `trim_media_item`: non-destructively set source in/out, playback speed, and timeline start; use `restoreFullSource: true` to make an agent-trimmed clip extendable to its original file duration
- `update_audio_item`: complete native AudioPanel controls—trim, volume/mute, fades, pan, loop, and playback speed
- `update_text_item`: complete native TextPanel controls—copy/timing, typography, colors/background, outline/shadow, placement/width, and animation
- `adjust_media_transform`: resize or reposition the actual editable media container; ordinary layout resizes materialize `size` and reset `scale` to 1
- `set_media_source_focus`: move source pixels within a cover crop without moving its container
- `set_media_layer_order`: move media between the normal, above-motion, above-text, and above-captions planes, then order overlays relative to peers in that plane
- `add_media_keyframe`: add motion or visual effects at any point inside an already-isolated timeline item; do not use it to create a temporary split layout on a full-duration source
- `update_editor_state`: batch changes to project or editor state
- `set_project_data`: one guarded path update
- `update_project_director_brief`: update original content, requirements, completed work, decisions, and pending verification after a coherent edit; Subclip appends live technical state
- `undo_editor_change` / `redo_editor_change`: native editor history

Relevant state roots are `canvasConfig`, `mediaData`, `audioData`, `subtitleData`, `customTextData`, `customHtmlData`, `hyperframeLayerData`, `remotionLayerData`, `threeDLayerData`, and `elementData`. Read existing objects and preserve unknown fields when updating them. Never write `threeDLayerData` through generic raw-state tools; use the named 3D operations. Generic raw-state tools intentionally reject the two framework roots; use their named runtime-layer tools.

## Processing

- `get_export_configuration`: read available containers/codecs, quality presets, alpha eligibility, and current export defaults before choosing a non-default format
- `export_video`: after an explicit export request, render MP4/H.264, WebM/VP9, MKV/VP9, or MOV/ProRes 4444 with explicit quality and transparency when needed; omit `startTime`/`endTime` for the complete project, or pass both (inclusive start, exclusive end) plus a meaningful `outputFileName` for one segment; pass `outputDirectory` only for an explicitly requested directory
- Pre-render finished ranges ahead of the final export (only when the creator asks): `prerender_segments`, `get_prerender_status`, `clear_prerenders`.
- `get_export_status`: external/status-check fallback for an exact export request; in-app agent runs are resumed on terminal events, and completion includes the saved display path
- `list_render_queue`: read-only view of the one shared render queue (running, waiting with `queuePosition`, latest finished renders); call it before `export_video` so an export that is already queued or done is not duplicated. All renders share it, one project render at a time; waiting is normal, and the export renders the project as saved when it was requested
- `cancel_job`: also cancels a queued or running render, pass the `export_video` request ID
- `list_social_accounts`: connected YouTube channels, X linked accounts, and Instagram accounts available to the signed-in creator; X results include display name, username/handle, avatar, provider account ID, and the linked-account ID required by publishing
- `publish_video_to_social`: after a separate exact confirmation, render and post/schedule the video on one connected platform; pass `confirmed: true` plus the reviewed caption summary and all platform copy fields, then end the in-app turn without polling
- TikTok (beta, see `subclip-tiktok`): `platform: "tiktok"` on the publish tools with a `tiktok` options object the USER chose; `tiktok_get_creator_info`, `tiktok_list_videos`. Editing or deleting a published TikTok video is not available through TikTok's public API: the user does it in the TikTok app. Until the TikTok app is audited, direct posts must be private (Only me) or a draft
- `transcribe_project`: local single-speaker or cloud transcription of an exact `mediaItemId` or native `audioItemId`; an exact item uses its current trimmed source range, offsets words to its timeline start, preserves other source batches, and replaces only that item’s older captions; omit both IDs only for an explicitly requested combined-timeline replacement; `detectSpeakers` is opt-in, cloud-only, and `expectedSpeakerCount` is optional
- `list_local_transcription_models` / `download_local_transcription_model`: offline Whisper models (free, no sign-in, works offline). `transcribe_project` with the default `mode: "local"` installs the model it needs by itself (a size chosen for this computer's memory unless `model` is given) and writes a normal captions layer; install ahead of time or cancel a download with these tools. `get_transcription_status` returns `progressPercent` (decimal), `secondsSinceLastProgress` and `progressState`: only `stalled` means stuck
- `stop_transcription`: stop local Whisper, the desktop cloud job, and its active Subclip Cloud server run before replacing routes
- `start_cloud_transcription`, `get_job_status`, `cancel_job`: asynchronous cloud flow

Confirm before paid cloud work when the current request has not already authorized it. Speaker diarization is available only through Subclip Cloud. Use local transcription only for ordinary single-speaker work when the user explicitly asks for local/on-device/no-cloud processing. Call `stop_transcription` before replacing any active route.
## Exact visual QA

- `view_current_frame`: render a full composed PNG at an explicit project `timeSeconds`; optionally focus the review with `targetType` and `itemId` for media, text, elements, motion graphics, dynamic captions, or 3D.
- `export_current_frame`: save the full composed PNG at an explicit `timeSeconds`.
- `add_3d_layer`: insert the same registry-backed model template used by the UI; `animationPresetId` defaults to `tilt-reveal` and remains editable with the 3D update and keyframe tools.
- `set_3d_screen_content`: bind project image/video media to a model screen; use `audioEnabled` and `volume` to keep requested video sound inside the 3D layer without creating a duplicate audio timeline item.

For generative changes to clip content (objects, colors, environment), route to `$subclip-video-generation` and discover `flux-video-edit`. Use ordinary timeline tools for trims/reframes. Talking portraits route to `$subclip-avatar-generation`; Avatar IV needs portrait AND supplied speech audio.

## Perception and critique

New in recent app versions; each line names the fallback for an older app. Skills: `subclip-perception`, `subclip-pacing`, `subclip-sound-mix`, `subclip-taste`, `subclip-self-critique`.

- `get_audio_analysis` (read-only): the mix in numbers for a range (`startTime`, `endTime`, `windowSeconds`, `include`): `mix` loudness and true peak, `lanes`, `speech.segments` with `gapDb` and `masked`, `music.tracks` with `bpm`, `beats`, `downbeats`, `sections`, `sfx` with `cutSync`, `overlap`, `issues`. Older app: `get_audio_timeline_sheet` summary and warnings
- `get_pacing_analysis` (read-only): `scenes`, `cutsPerMinute`, `shotLength`, `beatSync`, `textItems` with on-screen time verdicts, `captions`, `hook`, `deadAir`, `energy`, `issues`. Older app: `analyze_timeline` scenes plus item times from `read_project_section`
- `lint_text_style` (read-only): marks that read as AI-made or sloppy in text, captions, elements and layer strings; `findings` with `rule`, `excerpt`, `suggestion`. Older app: check by hand against `subclip-taste`
- `get_item_contact_sheet` (read-only): one item across its own duration (`itemId`, `count` or `times`, `isolate`). Older app: `get_timeline_contact_sheet` with `times` inside the item
- `review_segment` (read-only): one bundle for a range: sheet, audio, pacing, text findings, items, `rubric`, `reviewId`. Older app: call the sheet and analysis tools for the range
- `record_segment_review`: store scores (1 to 10 or null), issues, verdict and summary for a reviewed range; returns `overall`, `belowThreshold`, `nextAction`. Older app: note scores in the director brief
- `list_segment_reviews` (read-only): latest review per range, `stale`, `coverage`, `unreviewedRanges`, `lowestSegments`. Older app: keep the list in the director brief

## Several agents on one timeline

Skill: `subclip-multi-agent-timeline`. Older app without these tools: one agent per project, sub-projects and `merge_project_timeline`.

- `plan_timeline_segments` (read-only): split the timeline by `count`, `maxSeconds` or given `segments`; returns `segmentId`, `start`, `end`, `label`, `suggestedLaneOffset`, and `coordinatorId` once to the first caller
- `claim_timeline_segment`: reserve a range and a lane block for one `agentLabel`; returns `claimId`, `laneRange`, `expiresAt`; refused with the holder when it overlaps a live claim
- `release_timeline_segment`: give a claim back as soon as the work is done
- `list_timeline_claims` (read-only): holder, range, lanes, expiry, last activity and latest review score per claim
- While claims are live, pass `claimId` on every mutating call; edits outside the claim are refused, and ripple or global changes need the `coordinatorId`; refusals carry a stable `code`

## Creator style

Skill: `subclip-creator-style`. Older app without these tools: `fetch_linked_media` on the creator's own videos, then measure by hand.

- `learn_creator_style`: background job that studies the creator's own channel or videos (`urls`, `maxVideos`, `confirmOwnContent: true`, `workspaceId` or `workspaceName`); returns `jobId`
- `get_creator_style_status` (read-only): progress, then `videos` with stats, transcripts and sheets, the aggregate `profile`, `assets` and the workspace files written (`STYLE_STATS.md`)

## Reporting to the Subclip team

- `report_bug`: a tool failed or misbehaved and you cannot work around it. `request_feature`: something the user needs is missing. `submit_feedback`: general feedback. All three are text only (no screenshots), add the `[AGENT]` title prefix themselves, and never replace finishing the user's task. Read the `subclip-feedback` skill before the first report.

## Cleaning up after tests

- `cleanup_test_run` (namePrefix exactly `QA-<id>-`, confirmed true, QA runs only): stops renders of the test projects, deletes those saved projects AND recordings and clears their MCP renders from the Export Processes history and their exported files, in one call. Use it at the end of every test run. `remove_render_history` clears only the history entries for a project name prefix. For any other project use `delete_projects` after the user asks.

### Durable media context

- `get_media_context`: read existing context first; `includeContactSheet: true` attaches video contact sheets. If needed, inspect one moment using `fileId` and `inspectAtSeconds` before a wider scan.
- `list_media_without_context`: read-only list of files with no summary, flagged by missing summary, visual, contact sheet and transcript summary; empty videos first.
- `generate_media_context`: write local base context, technical metadata, video contact sheets and summaries of existing transcripts/captions. Optional `projectId` and `fileId`; omitted `fileId` processes all incomplete files. `contactSheets` and `transcriptSummaries` default to true. Returns per-file done/skipped/failed steps, remaining summary/visual gaps and a next-step hint. Unavailable in plan mode. Does not invent descriptions or transcribe speech.
- `describe_media`: save observed descriptions in one call with `items: [{fileId, summary, visual, transcriptSummary, tags, notes}]`; legacy single `fileId` and description fields still work. User edits win. First-time routine: list gaps, generate local context, inspect contact sheets, then describe the inspected files in one batch.
